# 智能轮椅辅助应用

## 项目概述
智能轮椅辅助应用是一款为智能轮椅用户设计的UI原型，旨在为行动不便的用户提供便捷的轮椅控制和管理体验。应用通过蓝牙和Wi-Fi与智能轮椅建立连接，实现远程控制、状态监测和设备管理等功能。

- [智能轮椅辅助应用 Demo](https://cmg-wheelchair-app.vercel.app/)

## 目标用户
- 智能轮椅的主要使用者（管理员）
- 家庭成员和照护者（普通成员）
- 紧急联系人

## 功能模块

### 1. 账号注册与管理
- **邮箱验证注册**：用户通过邮箱和验证码完成注册
- **家庭圈创建**：注册成功后自动创建家庭圈，注册用户成为管理员
- **成员管理**：管理员可添加和管理家庭成员
- **紧急联系人**：设置紧急情况下的联系人信息

### 2. 设备连接与配置
- **蓝牙扫描**：自动扫描并识别附近的"Orion"前缀的智能轮椅设备
- **设备连接**：通过蓝牙与轮椅设备建立连接
- **Wi-Fi配置**：为轮椅设备配置家庭Wi-Fi信息，实现网络连接
- **连接状态反馈**：显示设备连接的实时状态和结果

### 3. 远程控制
- **方向控制**：虚拟摇杆控制轮椅前进、后退、左转、右转
- **停车驻停**：一键停止轮椅移动
- **远程锁车**：远程锁定轮椅，使车载物理摇杆失效
- **控制模式切换**：提供不同的控制模式以适应不同场景

### 4. 设备管理
#### 4.1 状态查询
- **设备状态**：显示设备在线/离线状态
- **运行参数**：实时显示当前车速、行驶里程
- **位置定位**：显示轮椅当前位置和历史轨迹
- **电池信息**：显示电量百分比、电池健康度
- **故障诊断**：显示设备故障信息和处理建议

#### 4.2 设备添加
- **多设备管理**：支持添加和管理多台智能轮椅
- **设备命名**：为不同设备设置个性化名称
- **设备切换**：在多台设备间快速切换控制

### 5. 全局语音交互 ⭐ 核心功能
#### 5.1 全局语音访问
- **底部中央语音按钮**：黄色圆形按钮，在所有页面都可访问
- **全屏模式语音按钮**：在全屏对话窗中提供专用语音按钮
- **一致性交互**：无论在哪个界面，语音功能保持完全一致

#### 5.2 语音识别与交互
- **长按语音识别**：长按开始录音，松手立即结束并完成识别
- **顶部收音指示器**：黑色胶囊状指示器，显示收音状态和音波动画
- **流式文字上屏**：语音识别结果以打字机效果实时显示
- **智能文字补足**：松手时自动补足未完成的文字内容
- **多模态识别**：支持文本、图片等多种输入方式的智能回复

#### 5.3 智能对话系统
- **AI助手对话**：基于演示数据的智能问答系统
- **多种回复类型**：支持文本、日程卡片、提醒卡片、双卡片等丰富回复形式
- **上下文理解**：保持对话的连贯性和智能性
- **实时回复**：语音识别完成后自动触发AI回复流程

#### 5.4 对话窗口系统
- **半屏对话窗**：从顶部滑入的紧凑对话界面，显示最近3条消息
- **全屏对话窗**：完整的对话历史查看界面，支持所有历史记录
- **智能展开收起**：支持手动拖拽或点击展开/收起对话窗
- **流畅动画**：所有窗口切换都有平滑的过渡动画效果

#### 5.5 对话搜索与管理
- **智能搜索功能**：仿微信搜索界面，支持关键词搜索对话内容
- **实时搜索**：输入防抖300ms，提供流畅的搜索体验
- **关键词高亮**：搜索结果中关键词以黄色背景高亮显示
- **发送者过滤**：支持按用户消息或助手回复进行筛选
- **智能跳转**：点击搜索结果可直接跳转到对应的对话消息
- **消息定位**：跳转后目标消息会高亮显示3秒，便于用户定位

#### 5.6 卡片式回复展示
- **日程卡片**：蓝色渐变样式，显示提醒标题、时间和描述信息
- **提醒卡片**：黄色/红色渐变样式，支持紧急提醒的视觉区分
- **双卡片回复**：支持同时显示多个相关信息卡片
- **动态颜色**：根据内容类型和重要程度动态调整卡片颜色
- **图标支持**：每个卡片都支持自定义图标和样式

### 6. 我的
- **账号信息**：查看和修改账号基本信息
- **通知设置**：设置应用通知偏好
- **隐私设置**：管理数据分享和隐私选项
- **版本更新**：检查和执行应用更新
- **意见反馈**：提交问题和建议
- **关于我们**：显示应用相关信息

## 非功能需求
- **响应时间**：远程控制指令执行时间不超过500ms
- **兼容性**：支持iOS和Android主流设备
- **安全性**：采用加密通信，保护用户数据和控制指令
- **离线功能**：部分功能在无网络环境下仍可使用
- **电量优化**：降低应用对移动设备电量的消耗

## 交互流程

### 基础应用流程
1. 用户注册并创建账号
2. 引导用户添加第一台智能轮椅设备
3. 设备添加成功后，进入主界面
4. 用户可在主界面切换不同功能模块
5. 在远程控制界面可直接控制轮椅
6. 在设备管理页面查看轮椅状态
7. 在我的页面管理账号和应用设置

### 全局语音交互流程 🎙️
1. **语音触发**：在任意页面长按底部中央黄色语音按钮
2. **收音开始**：顶部出现黑色收音指示器，显示音波动画
3. **语音识别**：说话内容以打字机效果实时转换为文字上屏
4. **识别完成**：松手后立即完成识别，补足剩余文字
5. **对话展示**：半屏对话窗从顶部滑入，显示用户输入
6. **AI回复**：智能助手分析并返回相应的回复内容
7. **卡片展示**：根据回复类型展示文本、卡片或特殊内容
8. **交互管理**：可通过搜索查找历史对话，或展开全屏查看

### 对话搜索流程 🔍
1. **进入全屏**：点击半屏对话窗右上角展开按钮
2. **打开搜索**：点击全屏对话窗右上角搜索图标
3. **输入关键词**：在搜索框中输入要查找的关键词
4. **查看结果**：搜索结果实时显示，关键词高亮标记
5. **精确跳转**：点击任意搜索结果跳转到对应消息
6. **定位确认**：目标消息高亮显示，确保用户准确定位

## 本地开发

### 基本版本
如果您只想查看页面效果，可以直接在浏览器中打开HTML文件，或使用以下命令启动简单的HTTP服务器：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000 查看应用。

### 开发版本（带自动刷新）
为了更好的开发体验，可以使用我们提供的带自动刷新功能的服务器：

```bash
python3 server.py
```

此服务器会监控文件变化并在修改后自动刷新页面。

## 技术栈
- **前端框架**：HTML5/CSS3/JavaScript ES6+
- **UI框架**：TailwindCSS 用于快速样式开发
- **图标库**：Font Awesome 6.0 提供丰富图标
- **演示数据**：demo-conversations.js 模拟真实对话场景
- **响应式设计**：适配移动设备，支持触摸交互
- **动画效果**：CSS3 Transitions 和 JavaScript 动画
- **语音交互**：模拟语音识别流程（可集成真实API）

## 核心技术特性
- **防抖优化**：搜索输入防抖300ms，提升性能
- **智能高亮**：正则表达式关键词匹配和高亮显示  
- **流式显示**：打字机效果模拟真实语音识别体验
- **状态管理**：全局对话数据管理和同步更新
- **层级管理**：z-index 精确控制，确保UI层次正确
- **触摸优化**：支持长按、点击、滑动等移动端手势
- **内存优化**：智能清理和数据结构优化
